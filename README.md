# PTE Flow — Student App (Classroom Edition)

This repository contains the upgraded version of the PTE Flow Student App,
designed for both **self‑study** and **teacher‑controlled classroom sessions**.

## 🎯 Purpose

Originally built as a standalone practice app, this version introduces new
classroom features:

- Teacher broadcast listener
- Live drill mode
- Auto‑navigation to modules
- Synced countdown timers
- Module locking/unlocking
- Real‑time class session control

## 📦 Tech Stack

- React Native (Expo)
- TypeScript
- Firebase Firestore
- AsyncStorage
- Expo Router
